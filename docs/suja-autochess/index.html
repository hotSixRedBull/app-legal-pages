1. 앱에서 처리하는 정보

이 버전은 오프라인 자동 전투 게임입니다. 회원가입·로그인·광고·앱 내 결제·개발자 운영 클라우드 저장 기능이 없습니다. 앱이 개인정보를 수집하여 개발자 또는 제삼자에게 전송하는 기능은 제공하지 않습니다.

2. 기기 내 설정과 삭제

게임 계산과 진행은 실행 중 기기 메모리에서 처리됩니다. 음량, 전투 재생 속도, 진단 표시 여부, 튜토리얼 진행 여부는 앱 전용 저장공간의 로컬 설정으로 저장합니다. 이 설정을 개발자 서버로 전송하지 않습니다. Android 설정에서 이 앱의 저장공간·데이터를 지우거나 앱을 제거하면 로컬 설정을 삭제할 수 있습니다.

Android 0.3.0의 앱 매니페스트는 인터넷·광고 ID 권한을 요청하지 않으며 allowBackup=false로 설정되어 있습니다. 앱이 제공하는 클라우드 백업은 없습니다. 사용자가 직접 수행하는 파일 복사나 기기 제조사의 전송 도구는 별도 서비스의 정책을 따릅니다.

3. 배포 플랫폼과 사용자가 보내는 문의

Google Play, App Store, TestFlight가 처리하는 설치·진단·테스트 피드백은 각 플랫폼의 정책과 사용자가 선택한 설정을 따릅니다. 사용자가 직접 이메일이나 플랫폼으로 보내는 문의·테스트 피드백은 답변과 문제 해결을 위해 개발자에게 전달될 수 있습니다. 민감한 개인정보나 비밀번호를 보내지 마세요.
