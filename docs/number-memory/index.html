숫자 암기 훈련: 메이저 시스템 개인정보처리방침

시행일: 2026년 9월 16일

Alan Works가 제공하는 숫자 암기 훈련: 메이저 시스템(영문명: Number Memory: Major System, 패키지 이름: com.alan.majorsystem, 이하 “앱”)은 숫자와 연결한 이미지로 기억을 훈련하는 오프라인 학습 앱입니다.

1. 계정, 광고 SDK와 결제

앱에는 회원가입, 로그인, 개발자 운영 사용자 계정, 클라우드 동기화 또는 자체 분석 기능이 없습니다. 내부 테스트 빌드에는 동의를 기반으로 공개 테스트 광고 단위를 요청할 수 있는 Google Mobile Ads SDK 및 User Messaging Platform(UMP)이 포함됩니다. 학습 이력·복습 일정·인증 결과는 광고 요청이나 개발자 서버로 전송하지 않습니다.

현재 이 앱에는 판매 가능한 remove_ads 상품, 실제 광고 단위 또는 개발자 운영 구매 검증 서버가 구성되어 있지 않습니다. Google Play Billing SDK는 향후 비소모성 광고 제거 상품의 구조 검증을 위해 포함될 수 있으나, 이 방침 시행일 현재 구매 기능을 제공하지 않습니다.

동의를 받아 광고 요청이 이루어질 때 Google Mobile Ads SDK가 처리할 수 있는 IP 주소(대략적 위치 추정), 광고·앱 상호작용, 진단 정보 및 광고 ID·앱 세트 ID 등의 범위와 보관은 Google의 정책·사용자 동의·지역 및 기기 설정에 따릅니다. 자세한 내용은 Google 개인정보처리방침 및 Mobile Ads SDK 데이터 공개를 참고하세요.

2. 기기 안에 저장되는 데이터

학습 기능을 제공하고 재시작 후 진행을 복원하기 위해 학습 이력, 복습 일정, 인증·훈련 결과와 진행도, 화면 언어를 포함한 앱 설정을 기기의 앱 전용 저장공간에 저장합니다.

이 정보는 Room 데이터베이스와 DataStore에 기기 내부 데이터로 저장됩니다. 앱은 광고 동의 및 테스트 광고 요청을 위해 INTERNET 권한을 선언하지만, 학습 데이터의 백업·기기 간 전송 또는 개발자 서버 전송을 제공하지 않습니다.

3. 알림

사용자가 허용한 경우 Locker 회상 시점을 알려 주는 로컬 알림을 기기에서 예약할 수 있습니다. 알림은 개발자 서버를 통하지 않으며, 알림을 허용하지 않아도 앱의 학습 기능은 사용할 수 있습니다.

4. 보관과 삭제

로컬 학습 데이터와 설정은 사용자가 삭제할 때까지 해당 기기에 보관됩니다. Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 앱 전용 저장공간의 데이터가 삭제됩니다.

5. 방침 변경

앱의 데이터 처리 방식, 권한 또는 사용 SDK가 변경되면 이 방침을 함께 갱신하고 시행일을 변경합니다.

6. 문의

개인정보 또는 데이터 처리 관련 문의는 Google Play 스토어의 앱 페이지에 표시된 개발자 연락처를 이용해 주세요.
