# 앱 법적 문서

이 저장소는 `hotSixRedBull`의 Android 앱에 공개적으로 제공해야 하는 개인정보처리방침과 법적 문서만 호스팅합니다.

## 구조

- `docs/<app-slug>/`: 앱별 공개 문서입니다. GitHub Pages의 `main` 브랜치 `/docs`에서 배포합니다.
- `docs/flipmemory/`: 뒤집기억(FlipMemory) 개인정보처리방침입니다.

## 공개 범위와 관리

- 앱 소스 코드, 사용자 사진, 키·비밀번호·토큰·서비스 계정 파일, 내부 메모는 이 저장소에 넣지 않습니다.
- 앱의 데이터 처리 방식이 바뀌면 원본 앱 저장소의 배포 문서와 이 저장소의 해당 페이지를 함께 갱신합니다.
- Google Play에는 GitHub 파일 보기 주소가 아닌, GitHub Pages로 렌더링된 HTTPS 주소를 사용합니다.
